# Мастерская праздников

Отдельный сайт на **Next.js + React + Tailwind CSS**.

## Запуск

1. Установить зависимости:

```bash
npm i
```

2. Запустить dev-сервер:

```bash
npm run dev
```

По умолчанию проект стартует на `http://localhost:3002`.

## Страницы

- `/` — главная
- `/gallery` — фотогалерея (grid + lightbox)

## Компоненты

- `app/site/components/Header.tsx`
- `app/site/components/Hero.tsx`
- `app/site/components/PhotoGrid.tsx`
- `app/site/components/Lightbox.tsx`
- `app/site/components/Footer.tsx`

Контент галереи (placeholder) находится в `app/site/content/gallery.ts`.
